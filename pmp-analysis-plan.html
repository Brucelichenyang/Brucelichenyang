模块三：三大领域能力图谱（Core）中国PMP考生的知识结构特征分析
ATBN四个等级说明

A · Above Target

高于目标，深绿 — 优秀，全面扎实

T · Target

达到目标，浅绿 — 合格，保持学习

B · Below Target

低于目标，黄色 — 偏弱，针对补强

N · Needs Improvement

需显著改进，红色 — 薄弱，重点辅导

3.1 ATBN分布分析
构建"群体能力热力图"：分析三大领域（人员42% / 过程50% / 业务环境8%）中，A/T/B/N各等级考生分布占比，识别全体考生最普遍的薄弱领域。
3.2 领域组合模式分析
组合类型示例预估占比预估通过率特征
全优型 AAA ?% ~100% 全面扎实，推荐进阶认证
均衡型 ATT / TAT ?% 高 稳定优质，维持现有学习节奏
偏科型 ABT / TAB ?% 中 存在明显薄弱领域，需针对性补强
危险型 含 N 的任意组合 ?% 低（大概率Fail） 出现N等级，需重点辅导或重考
3.3 中国考生特殊性分析（假设验证）
🔑 高价值洞察： 假设验证——中国考生"过程"(Process)偏强（擅长记忆流程/刷题），"人员"(People)和"业务环境"(Business Environment)偏弱（软技能/战略思维不足）。
重点验证：沟通、冲突管理、领导力类题目是否存在系统性偏低现象？
过程 Process (50%)

预期偏强：中国教育体系强调流程记忆，刷题效果好

人员 People (42%)

预期偏弱：软技能、情境判断题，文化背景差异明显

业务环境 BE (8%)

预期偏弱：战略合规/治理/商业价值，抽象度高

模块四：知识模块得分深度分析（Deep Dive）利用中方掌握的模块分数数据进行精细化分析
4.1 模块得分分布
指标说明分析价值
均值 / 中位数每个模块的集中趋势识别全体考生的平均能力水平
标准差每个模块的离散程度差异大的模块说明考生分化明显
得分分布形态正态分布 / 左偏 / 右偏判断模块难度特征
高低分考生特征高分区间 vs 低分区间的背景对比识别高分群体共同特征
4.2 关键模块识别——四象限模块地图
难度指数 = 1 − 该模块平均正确率  |  区分度 = 高分组正确率 − 低分组正确率（Item Analysis经典方法）
⚠️ 重点关注
难度高 + 区分度高
决定通过与否的关键模块
需重点备考
✅ 核心必考
难度低 + 区分度高
基础分，必须拿满
高通过率保障
🔻 效率存疑
难度高 + 区分度低
大家都难，投入产出低
可择优备考
📚 基础巩固
难度低 + 区分度低
基础知识，稳定得分
保持不失分
← 题目越难（难度指数高） ↑ 区分度高（能区分高低分） 题目越易（难度指数低）→

下一步调整建议获取实际字段后的5个关键确认事项
  • ① 个人背景字段确认 是否涵盖行业、学历、年龄、备考时长等信息？字段完整程度决定"模块一/五"的分析深度。
  • ② 知识模块分数粒度确认 中方掌握的模块分数，粒度细化到Task级（子任务）还是Domain级（三大领域）？影响"模块四"的可行性。
  • ③ 时间维度确认 是否有多批次（多期）历史数据支持趋势分析？否则"模块七"将仅做截面分析，不做预测。
  • ④ 企业维度数据确认 考生数据是否能关联到具体企业？若可以，则可支持企业级人才盘点和B端服务产品设计。
  • ⑤ 重考数据追踪确认 同一考生的多次考试记录是否可追踪？支持"重考提升分析"和备考建议的个性化优化。
⚡ 根据实际字段的丰富程度，决定哪些模块做深（Full Analysis），哪些模块简化处理（Summary Only）， 在有限资源下最大化数据洞察价值。
